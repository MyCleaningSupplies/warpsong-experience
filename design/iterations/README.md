# Main Application Interface Iterations

## Goal
Make source history and liner context immediately visible, with clear first actions for new users.

## Variant A (V1): Studio Grid
- Balanced dashboard with places, context status, and source spotlight.
- Good default for mixed usage: listening, reading, and source review.

## Variant B (V2): Story Canvas
- Narrative-first visual tone.
- Emphasizes liner notes and personal context while keeping source cards visible.

## Variant C (V3): Evidence Mode
- Credit and provenance oriented.
- Stronger contrast for sample metadata, label/year clarity, and source audit behavior.

## 10s Clarity Test
Ask a new viewer after 10 seconds:
1. Where does a sample come from (artist/title/label/year)?
2. Why is that sample personally relevant?
3. Where is the sample used in the track?

Pass criterion: at least 2/3 answered correctly without guidance.

## Implementation Notes
- Variants are switchable in-app via status chips and Start menu.
- Source spotlight is now visible on the desktop by default.
- Source ledger now highlights exact credits before the full table.
- A starter window explains immediate actions in the app.
